Here is how you can write unit tests for the given python code using pytest.

```python
import pytest
from io import StringIO
import sys

def test_fizzbuzz():
    capturedOutput = io.StringIO()          
    sys.stdout = capturedOutput

    fizzbuzz(1, 2, 10)

    sys.stdout = sys.__stdout__

    assert capturedOutput.getvalue() == """
    1
    2
    Fizz
    4
    Buzz
    Fizz
    7
    8
    Fizz
    Buzz
    """

def test_fizzbuzz_edge_cases():
    capturedOutput = io.StringIO()          
    sys.stdout = capturedOutput

    fizzbuzz(1, 3, 1)

    sys.stdout = sys.__stdout__

    assert capturedOutput.getvalue() == """
    1
    """
```

In the above code, we are testing the `fizzbuzz` function with different edge cases.

- `test_fizzbuzz` tests the function with normal inputs.
- `test_fizzbuzz_edge_cases` tests the function with edge cases.

You can run these tests using pytest by executing `pytest -v test_fizzbuzz.py` in your terminal.

Please note that the `fizzbuzz` function is not defined in the provided code. You need to define it according to your requirements.
